# 生态补偿核算线领域约定

项目面向集体林权改革与林下产业协作场景，业务记录需要区分来源、发生时间与当前有效版本。涉及个人、机构或敏感地点的信息只应向职责范围内的角色开放，所有对外结果都应能够追溯到采用的数据版本。

## 核算对象与不可变规则

核算把以下五类事实固化为**只追加事件账本（append-only ledger）**，当前状态由事件归约得到，任何更正都是新增事件，旧记录保留可追溯：

1. **保护承诺（commitment）**：林农对地块签订逐期有效的承诺，含逐项承诺事项；撤回承诺使后续期别不再认定。
2. **有效面积（effective area）**：以监测证据认定，共有林地按经备案的分摊比例（和为 1）逐户认定；扣减事件按责任归属与严重程度折减。
3. **监测证据（evidence）**：区分来源机构、观测时间、记录时间与补偿期。证据生命周期为
   `submitted（待确认）→ confirmed（已确认）→ superseded（被更正替代）/ rejected（已撤销）`。
   提交时自动异常初筛（面积超登记 110%、不足登记 50%、郁闭度越界等）；**异常证据未经显式豁免确认不得参与核算**，
   已撤销证据不能重新确认，监测更正是「新证据替代旧证据」（supersede 链），引用自动沿链跟进。
4. **扣减事件（deduction）**：火情、破坏等事件按期、按地块、按责任户登记；事后申诉成立以「回退事件」处理，旧事件保留。
5. **资金批次（batch）**：生命周期 `draft → settled → published → paid`。草稿期可反复换版试算，
   每次定稿都完整留痕；**发布后结果冻结，不能重新定稿或换版，更正只能以调整批次追加**
   （金额为正=追补，为负=追回），多次调整沿调整链取最近全量结果作差，不重复计差。

## 证据采信原则

- 只有 `confirmed` 证据，且被该户在该期**显式引用（citation）**，才参与该户核算；
  同一证据被同一户重复引用只计一次，但可被多户分别引用。
- 同一地块同一期存在多份不同机构/时间的已确认证据时，有效面积按**就低原则**采信并给出提示。
- 证据按补偿期严格隔离，不同期别数据互不串算。

## 规则版本（可复算）

- `v1 基线面积版`：有效面积 × 50 元/亩，管护与证据质量不参与。
- `v2 贡献导向版`：在 v1 基础上乘承诺履行系数（0.9~1.1）、管护强度系数（0.9~1.25）、证据质量系数（≤1.15），
  让承担长期管护的人可被核算识别。

每次核算输出**输入指纹（SHA-256）**：相同账本状态 + 相同规则版本必然得到相同金额与指纹。
批次的每次定稿保存逐户、逐地块、逐期的金额及与上一稿的**变化说明**，金额变动必须能对应到具体原因
（规则换版、认定面积、扣减面积、系数、证据进出采信集合）。

## 代码结构

- `src/domain/money.mjs`：整数分金额与舍入
- `src/domain/rules.mjs`：规则版本（纯函数，发布即冻结）
- `src/domain/store.mjs`：事件账本、状态归约、异常初筛
- `src/domain/batch.mjs`：批次生命周期、核算引擎、差异说明、调整链
- `src/domain/index.mjs`：领域命令门面
- `src/domain/persistence.mjs`：JSONL 导出与重放
- `src/domain/report.mjs`：公示材料格式化
- `src/domain/scenario.mjs`：跨村水源涵养林验收剧情夹具
- `src/http/app.mjs`：只读查询与试算接口
- `scripts/acceptance-demo.mjs`：公示前验收演示
