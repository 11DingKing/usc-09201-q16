# 生态补偿核算线

把保护承诺、有效面积、监测证据、扣减事件和资金批次固化为**可复算规则**的独立核算项目。监测数据来自不同时间和机构，异常值未经确认不得参与计算；结果发布后只能追加调整，每一笔变化都能逐户归因、追溯到证据。

## 快速开始

```bash
npm test                 # 13 项领域不变量测试
node scripts/demo.mjs    # 跨村水源涵养林完整核算演练（中文对账报告）
npm start                # 启动服务，只读公示接口见下
```

启动后：

- `GET /health` — 服务状态
- `GET /api/accounting/demo` — 演练场景的发布结果、换版差异、追加调整与逐户闭合对账（JSON）

## 关键规则（两版）

| 口径 | 2024-v1（粗略面积版） | 2025-v2（按效计偿版） |
| --- | --- | --- |
| 单价 | 统一 36 元/亩 | 全面保护 48／限制利用 38／一般管护 30 元/亩 |
| 证据加权 | 无（任意 1 条即可） | 1/2/3 项指标确认 → 权重 0.7/0.85/1.0 |
| 长期管护津贴 | 无 | 满 5 年 8 元/亩、满 3 年 5 元/亩 |
| 扣减上限 | 50% | 60% |

有效面积 = 登记面积 × 共有份额 × 证据权重；监测证据先 `pending` 后确认，拒绝/撤销/待确认的证据全部被门控剔除并留痕；同一证据跨系统重传只计一次。

## 演练时间线（scripts/demo.mjs）

一宗跨青溪、岭脚两村、600 亩、五户共有 + 邻村单户 120 亩的水源涵养林：

1. **2026-02-10 v1 公示**：统一单价，总额 25,272 元；一条水质异常值尚处 pending 被门控剔除。
2. **2026-02-20 v2 换版**：按效计偿总额 33,168 元——2018 年起全面禁伐的老护林员增加 3,600 元，承诺晚、管护轻的农户下降，差异逐户列明原因。
3. **2026-03-05 发布后撤销**：一条已采信证据因探头召回被追加撤销，已发布金额不变，对五户出具追回单（ADJ-0001~0005）。
4. **2026-03-10 跨期追补**：赵东来观测于 2025 补偿期内的生物多样性证据材料补齐后确认，不重开旧批次，出具追补单 ADJ-0006（+1,008 元）。
5. **闭合对账**：各户「当前发布＋追加调整」与按最新台账重算金额完全一致。

## 设计原则

- **可复算**：同一台账＋同一 asOf＋同一规则版本 ⇒ 同一结果（测试锁定）。
- **append-only**：监测撤销、扣减确认、规则激活全部是追加事件，旧事实永不改写。
- **发布即冻结**：快照带输入指纹（批次|版本|asOf|事件数），换版不覆盖旧公示，发布后仅可通过调整单调账。
- **贡献可证**：差别单价、指标权重与管护年限津贴让长期承担保护的农户可凭监测证据与承诺档案证明贡献。

业务数据与敏感配置应存放在受控环境中。详见 `docs/domain.md`。
